# Спецификация графики

Для [@mitzzi4] (ibis Paint) и [@Lix2w78] (Procreate). Векторы не используются нигде.

Главное правило, из которого следует всё остальное: **детали питомца рисуются слоями в одном документе и экспортируются послойно**. Тогда они совпадают по положению автоматически, и [@zYafALL] не надо подбирать координаты вручную.

## Общие правила экспорта

| Группа | Размер экспорта | Формат |
|---|---|---|
| Детали питомца | 1024 × 1024 | PNG с прозрачностью |
| Предметы покупок, цели | 256 × 256 | PNG с прозрачностью |
| Иконки интерфейса | 192 × 192, **монохром** | PNG с прозрачностью |
| Иллюстрации к заданиям | 1024 × 768 | PNG |
| Фон комнаты | 1080 × 1920 | PNG |
| Иконка приложения | 512 × 512 | PNG без прозрачности |

- Фон холста отключить везде, кроме фона комнаты и иконки приложения.
- Конвертацию в WebP делает [@zYafALL] в Android Studio — от дизайнеров нужен PNG.
- Имена файлов **только латиницей**, строчными, через подчёркивание.
- Иконки интерфейса рисуются одним цветом (белый силуэт) — тогда их можно перекрашивать кодом под светлую и тёмную тему.

## Питомец — [@mitzzi4]

### Структура документов

Три документа, по одному на стадию роста: `pet_stage1`, `pet_stage2`, `pet_stage3`.
Холст 2048 × 2048, экспорт в 1024 × 1024.

Слои внутри каждого документа:

```
тело                    → pet_s1_body.png
лапы                    → pet_s1_paws.png
хвост (или уши)         → pet_s1_tail.png
глаза, вариант 1        → pet_s1_eyes_round.png
глаза, вариант 2        → pet_s1_eyes_oval.png
глаза, вариант 3        → pet_s1_eyes_sly.png
глаза закрытые          → pet_s1_eyes_closed.png
рот нейтральный         → pet_s1_mouth_neutral.png
рот довольный           → pet_s1_mouth_happy.png
рот грустный            → pet_s1_mouth_sad.png
рот удивлённый          → pet_s1_mouth_surprised.png
```

11 слоёв × 3 стадии = **33 файла**.

### Цветовые варианты

Три цвета тела. Не перерисовывать: дублировать слой тела и сдвинуть оттенок через
`Фильтр → Оттенок/Насыщенность` в ibis Paint.

```
pet_s1_body_a.png   pet_s1_body_b.png   pet_s1_body_c.png
```

**+6 файлов** (по два дополнительных на стадию).

### Кастомизация: откуда берутся 9 комбинаций

**3 цвета × 3 варианта глаз = 9.** Всё доступно бесплатно на экране создания питомца — это требование ТЗ п. 2.6, оно проверяется созданием двух профилей подряд.

Аксессуары (шапка, шарф, очки) — **не** часть этих девяти: они покупаются в магазине за монеты и относятся к необязательным расходам.

### Аксессуары

По одному файлу на аксессуар, размер под стадию подгоняет код:

```
acc_hat.png     acc_scarf.png     acc_glasses.png
```

Рисовать в расчёте на стадию 2 (средний размер). **3 файла.**

### Что не рисуем

Покадровую анимацию не делаем. Питомца оживляет [@zYafALL] кодом из этих же слоёв: дыхание — масштабирование тела, моргание — подмена слоя глаз, покачивание — поворот хвоста, радость — подпрыгивание.

**Итого у [@mitzzi4]: 42 файла.**

## Передача файлов

1. Дизайнеры складывают PNG в общую папку в облаке по подпапкам `pet/`, `items/`, `icons/`.
2. Раз в день PNG переносятся в `design/exports/<подпапка>/` репозитория — как есть, без правок.
3. В `app/src/main/res/` попадает только WebP без потерь и только то, что уже рисует код.
   Для питомца это делает `python tools/split_pet_base.py`; остальное пока конвертируется
   вручную в Android Studio (правый клик по PNG → Convert to WebP, lossless).
4. Исходники ibis Paint и Procreate в репозиторий **не кладём** — только экспорт.

PNG в `app/src/main/res/` не кладём вообще: те же картинки в WebP без потерь весят втрое
меньше, а `design/exports/` остаётся источником, из которого всё пересобирается.

## Приоритет отрисовки

Порядок важен: без первых двух пунктов разработка стоит.

1. Питомец, стадия 2, все слои — нужен для главного экрана
2. Иконки интерфейса — нужны для навигации
3. 8 позиций покупок
4. Питомец, стадии 1 и 3
5. Цели накопления
6. Иллюстрации к заданиям
7. Фон комнаты, иконка приложения
