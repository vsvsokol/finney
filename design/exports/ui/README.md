## Что уже измерено

Результаты перенесены в комментарии `ui/components/FinneyButton.kt`. Коротко: заливка кнопки **плоская**, нижняя
полоса — **вторая заливка** на четверть высоты с прямой границей, обводка
**10 при высоте 120**, блик — **непрозрачно белый**.

Это отменяет прежние заметки про вертикальный градиент и формулу обводки
«15 × кегль / 200»: они были сняты на глаз и не подтвердились.

Мерить так (Pillow уже стоит, интерпретатор — `py`):

```bash
py -c "
from PIL import Image
im=Image.open('design/exports/ui/button-rest-420x120.png').convert('RGBA')
px=im.load(); print(px[210,20], px[210,100])
"
```
